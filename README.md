# インフレアドベンチャー

昔のCGIゲーム「FFA」風の、ブラウザで遊べるインフレRPG。数字がどこまでも大きくなっていく冒険を楽しむゲームです。

**遊ぶ：https://amane-pipippi0630.github.io/inflation_adventure/**

## 遊び方
- 上のページを開くだけ（`index.html` 1ファイルでも動きます）。スマホでも遊べます。
- セーブはブラウザに保存されます。「記録・ヘルプ」の「セーブコードをコピー」でバックアップでき、タイトル画面の「セーブコードから復元する」で戻せます。
- 最初は隠居じいさんの「はじまりの手ほどき」に従って、町をひととおり回ってみてください。
- 更新の内容は、ゲーム内の「記録・ヘルプ → 更新ログ」で見られます。

## 主な要素
- 職業：下位・中位・上位。熟練度とマスター、職業ごとに覚える極意
- 冒険・闘技場・冒険者ギルド（依頼とランク）
- 属性と相性、物理と魔法、MPと技、状態異常
- 装備（素材を集めて鍛冶屋で合成）・装飾品
- 酒場（お酒・はしご酒・熟成・飲み比べ・噂話）・ギャンブル場
- 転生、実績、長押しで連戦、戦闘ログ
- ほかにも、遊んでいくうちに見つかる要素があります
