# インフレアドベンチャー

昔のCGIゲーム「FFA」風の、ブラウザで遊べるインフレRPG。`index.html` 1ファイルで動く（ビルド不要）。

## 遊び方
`index.html` をブラウザで開くだけ。セーブはブラウザに保存される。
「記録」画面の「セーブコードをコピー」でバックアップでき、タイトル画面の「セーブコードから復元する」で戻せる。

## 主な要素
- 職業：下位12・中位12・上位12＋隠し職業。ジョブレベル／マスター報酬／修練場
- 冒険（第300層まで）・闘技場・神々の座、ほか
- 装備・装飾品・ギャンブル場（ハイ&ロー／スロット／ルーレット／丁半）
- 実績、長押し連戦、戦闘ログ
